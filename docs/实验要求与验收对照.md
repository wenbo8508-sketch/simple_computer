## 三、如何复现验收结果

```powershell
# 1) 构建 + 跑测试
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH="C:/Qt/6.11.2/mingw_64" -DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure      # Totals: 43 passed, 0 failed

# 2) 运行程序，用键盘输入 100 + 10 % =  应得 110
.\build\simple_computor.exe

# 3) 重新生成界面截图（Windows 桌面下字体才完整）
cmake -S . -B build -DBUILD_SHOTS=ON
cmake --build build --target shots
$env:QT_QPA_PLATFORM = "windows"; .\build\shots.exe docs/screenshots
```
